## 2. 模块划分与依赖

| 模块 | 职责 | 依赖 |
|---|---|---|
| core | 操作日志、通知中心、分页、异常、中间件、工具函数 | 无 |
| accounts | User/Role/Permission、JWT、个人中心、管理接口 | core |
| files | 文件夹/文件/分片上传/共享链接 | core, accounts |
| notes | 笔记/版本/标签/分享 | core, accounts |
| projects | 项目/看板/卡片/评论/活动 | core, accounts |
| im | 会话/消息/未读 | core, accounts |
| tools | 纯函数工具接口 | 无 |
| dashboard | 统计聚合 | 全部 |
| ws_app | WebSocket 消费者 + 事件推送封装 | channels |

## 3. 关键设计

### 3.1 RBAC 权限体系
- `Permission(module, code, name)` 20 个权限点 → `Role`（admin/user 内置）→ `User.roles` M2M
- `User.has_permission_code()`：超管恒真；`MyPermissionView` 输出当前用户权限编码集合
- 管理类接口 `IsAdminUser` 或 owner 校验；业务接口按对象归属校验（owner/member）
- 前端 `useUserStore.hasPerm(code)` 可做按钮级隐藏（预留）

### 3.2 分片上传与秒传
```
前端：file.slice(5MB) → upload/init (得 upload_id) → 逐片 upload/chunk（FormData）
后端：ChunkUpload 记录已传分片索引（JSON），断点续传时跳过重复块（幂等）
合并：按 index 顺序拼接 → SHA1 全文件校验 → 同 SHA1 命中则删除物理副本复用存储（秒传）
清理：合并后 rmtree 临时目录；图片经 Pillow 生成 400px 缩略图
```
- 磁盘布局：`media/_chunks/{upload_id}/part_{index:06d}` → `media/files/{uid}/{yyyymm}/{name}`
- 路径安全：所有拼接经 `_safe_join` 校验 realpath 前缀

### 3.3 WebSocket 统一消息协议
```
连接：/ws/notify/ → AuthMiddlewareStack → 未登录 4001 关闭 → 加入 user_{id} 组
客户端→服务端：{"type":"ping"} / {"type":"typing","session_id":N}
服务端→客户端：{"type":"notification"|"file.event"|"board.event"|"chat.message"|"chat.typing", "data":{...}}
心跳：前端 30s ping，服务端回 pong；断线 3s 自动重连
```
- `ws_app.events.py` 提供 `notify_file_event / notify_board_event / notify_chat_message` 供业务侧调用
- Channel Layer：`REDIS_URL` 存在用 Redis，否则 InMemory（单进程开发开箱即用）

### 3.4 笔记版本快照
- 保存逻辑：内容变化 → 先写 `NoteVersion(v=当前version, 旧title, 旧content)` → `note.version += 1`
- 回滚逻辑：先保存当前版本 → 恢复目标版本内容 → version+1（回滚可逆）

### 3.5 看板拖拽排序
- 卡片 `sort_order` 列内排序；`move` 接口把卡片插入目标列目标位置后，重算该列全部卡片顺序（单次事务内多条 UPDATE）

### 3.6 通知与消息解耦
- `core.models.notify()` 统一写 Notification；IM 发送时给其他成员 `UnreadCounter.count += 1` 并 notify
- 前端 App.vue onMounted 启动 WS + 拉取未读；收到 `notification` 事件自动刷新红点

## 4. 安全设计
- 全部写接口经 OperationLogMiddleware 落操作日志（跳过 GET/admin/静态/认证路径）
- 文件下载/预览/删除均校验 `owner`；共享访问走独立 token 且校验过期
- `_safe_join` 防目录穿越；文件名重名自动加 `(n)` 后缀
- JWT access 12h / refresh 7d；前端 401 自动刷新重试一次
- 分页上限 100，防止全表拉取
