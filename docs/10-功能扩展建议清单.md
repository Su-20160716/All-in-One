# 全能协作平台 · 新功能扩展建议清单（115 项）

> 文档性质：**功能点子库**。基于对 `backend/` 16 个 app、`frontend/src/views` 41 个 .vue、`FEATURES.md` 与既有 docs 的实读，**在已有《09-平台评价与扩展路线图》100 项之外，再给一份有增量的建议清单**，避免纯重复。（规模数字口径：`scripts/stats.py`，2026-10-24 复核）
> 每个模块按「做什么 + 为什么值得 + 成本（低/中/高）」三列给出，按模块分 11 组，共 **115 项**。
> 建议落地优先级统一标注：⭐=性价比高可先做，🔥=架构/体验必做，其余为可选扩展。

## 落地优先级速览

**⭐ 先做（性价比最高，约 12 项）**：#1 标签、#19 笔记 AI 大纲、#27 看板到期提醒、#30 燃尽图、#59 全局命令面板、#61 AI 自动标签、#62 AI 每日摘要、#66 写作助手内嵌、#70 API 限流、#71 数据备份、#72 审计可视化、#77 权限矩阵可视化。

**🔥 架构/体验必做（约 10 项）**：#7 文件版本历史、#25 看板多视图、#37 IM 富媒体、#56 统一回收站、#58 语义搜索、#89 CodeForge 拆分、#104 开放 API Key、#105 Swagger、#108 存储适配、#113 时区统一。

其余 90 余项按模块需要逐步铺开。**新增功能的共同原则：先做能复用既有管道（通知 WS / 存储分析 / AI 本地降级）的，避免再造基础设施。**
