# 04 数据库设计

> 开发默认 SQLite；`POSTGRES_*` 环境变量存在时自动切换 PostgreSQL。全部主键为 BigAutoField。

## 模型总览（9 个业务 app）

```
accounts: User · Role · Permission
files:    Folder · FileMeta · ChunkUpload · ShareLink
notes:    Note · NoteVersion · NoteTag
projects: Project · Board · TaskCard · CardComment · ProjectActivity
im:       ChatSession · ChatMessage · UnreadCounter
core:     OperationLog · Notification
```

## 一、accounts

### User（扩展 AbstractUser，AUTH_USER_MODEL）
| 字段 | 类型 | 说明 |
|---|---|---|
| nickname | Char(50) | 昵称 |
| avatar | ImageField | media/avatars/ |
| phone | Char(20) | 手机号 |
| bio | Char(255) | 简介 |
| is_disabled | Bool | 手动禁用 |
| storage_quota_mb | Int 默认 2048 | 存储配额 |
| roles | M2M → Role | 用户角色 |
| last_active_at | DateTime | 最近活跃 |

### Role
name(50,uniq) · code(50,uniq) · description · is_builtin · created_at

### Permission
module(choices) · code(64,uniq) · name(100) · roles(M2M ← Role.permissions)

## 二、files

### Folder（虚拟目录树，与磁盘解耦）
name(200) · parent(FK self, null) · owner(FK User) · created_at · updated_at

### FileMeta
| 字段 | 类型 | 说明 |
|---|---|---|
| name | Char(255) | 文件名 |
| folder | FK Folder, null | 所属文件夹 |
| owner | FK User | 所有者 |
| storage_path | Char(500) | media 下相对路径 |
| size | BigInteger | 字节 |
| sha1 | Char(40) + index | 秒传/去重 |
| kind | Char(16) | image/text/video/audio/archive/other |
| ext | Char(16) | 扩展名 |
| thumbnail_path | Char(500) | 缩略图相对路径 |
| is_deleted / deleted_at | Bool / DateTime | 回收站 |

### ChunkUpload（分片上传任务）
upload_id(UUID, uniq) · user · filename · folder_id(Int) · file_size · chunk_size · total_chunks · uploaded_chunks(JSON list) · sha1 · temp_dir · status(uploading/completed) · created_at · updated_at

### ShareLink
token(32, uniq) · file(FK, null) / folder(FK, null) · created_by · permission(view/download/edit) · expire_at(null=永久) · download_count · created_at

## 三、notes

### Note
title(200) · content(Text) · owner · parent(FK self, null) · tags(M2M → NoteTag) · is_pinned · is_favorite · is_public · share_token(32, index, 自动生成) · version(Int 默认 1) · created_at · updated_at

### NoteVersion
note(FK) · version(Int) · title · content · created_by(FK null) · created_at；`unique(note, version)`

### NoteTag
name(50) · owner；`unique(name, owner)`

## 四、projects

### Project
name(120) · description · color(16) · owner · members(M2M User) · is_archived · created_at · updated_at

### Board（看板列）
project(FK) · name(60) · sort_order · created_at

### TaskCard
board(FK) · title(200) · description · priority(low/medium/high/urgent) · status(todo/doing/done) · assignees(M2M User) · labels(JSON list) · due_date(Date, null) · sort_order · created_by · created_at · updated_at

### CardComment
card(FK) · author(FK) · content · created_at

### ProjectActivity
project(FK) · user(FK null) · action(100) · target(200) · created_at

## 五、im

### ChatSession
name(120) · type(direct/group) · members(M2M User) · owner(FK null) · last_message(500) · last_message_at · created_at

### ChatMessage
session(FK) · sender(FK null) · content(Text) · is_read · read_by(JSON list) · created_at

### UnreadCounter
user(FK) · session(FK) · count；`unique(user, session)` —— 未读数免全表扫描

## 六、core

### OperationLog（操作日志）
user(FK null) · module(32) · action(choices) · target(255) · detail(Text) · ip · created_at；`-created_at` 排序

### Notification（通知中心）
recipient(FK) · category(system/file/note/project/message/share) · level(info/success/warning/danger) · title(200) · content(Text) · link(500) · is_read · created_at

## 关系要点

- 文件夹/文件/笔记/项目：**归属校验靠 owner 外键**，删除策略 `CASCADE`（文件夹删→子级联）
- 看板成员：Project.members M2M；访问控制 = owner 或 member
- 聊天已读：消息级 `read_by`（JSON 用户 ID 数组）+ 会话级 `UnreadCounter` 计数，两者配合
- 权限链路：Permission.roles → Role.users → User（`has_permission_code`）
