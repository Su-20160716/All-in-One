# 06 UI 设计说明

> 设计依据：doubao-ui-design 工艺规范（console 工作台形态）——「B 端满屏是图就是设计错误；一个数配一个环比；四种状态齐全」。

## 1. 形态定位

`web-console` 工作台/管理后台形态：**亮场** + 左侧深色导航 + 内容区卡片网格。目标不是炫技，而是信息密度、状态完整、操作可达。

## 2. 设计令牌（Tailwind theme 落地）

### 色板
| 角色 | 取值 | 用途 |
|---|---|---|
| 中性底 | ink-50 `#f8fafc` | 页面背景（不用纯白） |
| 表面 | white / ink-100 `#f1f5f9` | 卡片 / 列背景 |
| 文字 | ink-900→ink-400 | 标题→次要信息层级 |
| **强调色（唯一）** | brand-600 `#0284c7`（sky） | 主按钮、激活态、链接、进度 |
| 语义色 | emerald / amber / rose | 成功 / 警告 / 危险（只做状态，不做装饰） |

**约束**：同一块面积内只允许一个强调色；`#0ea5e9` 系 sky 蓝用于品牌动作，避免大面积极紫/靛蓝。

### 字阶（有断崖，不是“大一点的正文”）
| 用途 | 字号/字重 |
|---|---|
| 页面标题 | 15-16px / semibold |
| 卡片数据主值 | 24px / bold |
| 正文 | 14px / normal |
| 辅助信息 | 11-12px / ink-400 |
| 代码/工具输出 | 12px / mono（JetBrains Mono 等宽） |

### 圆角角色（只有可点的东西才是圆的）
| 角色 | 值 | 用于 |
|---|---|---|
| control | 6px | 按钮、输入框、菜单项 |
| card | 10px | 卡片、弹窗 |
| pill | 9999px | 标签、状态点、头像、进度条 |

### 栅格与留白
- 内容区 `p-5`；卡片内 `p-4/p-5`；列表行 `py-2.5`
- 卡片间距 12-16px；卡片缝隙可小到一线（表格行 `divide-y`）
- 看板列间距 12px，列内卡片 8px

## 3. 组件规范（style.css @layer components）

| 组件 | 类 | 状态覆盖 |
|---|---|---|
| 按钮 | `.btn-primary/.btn-ghost/.btn-outline/.btn-danger` | hover / disabled |
| 输入 | `.input` | focus ring 2px brand-500/30 |
| 卡片 | `.card` | shadow-card 1px 弱阴影 |
| 标签 | `.tag/.tag-brand` | 状态色 |
| 菜单 | `.menu-item(.active)` | 激活 = brand-600/20 底 + brand-300 字 |
| 表格 | `.th/.td` | 表头 12px 中灰，行 hover |

## 4. 关键界面与状态完整度

| 页面 | 正常态 | 空态 | 加载/错误态 |
|---|---|---|---|
| 工作台 | 4 张统计卡 + 存储条 + 双栏 | 无笔记/无通知提示 | toast |
| 文件 | 树 + 列表 + 上传进度条 | “此文件夹为空”引导 | 加载中… |
| 看板 | 三列卡片 + 拖拽 | 无项目引导创建 | toast |
| 消息 | 会话列表 + 气泡聊天 | 未选会话占位 | toast |
| 工具 | 12 Tab + 输入/输出 | 空输出不渲染 | ok:false 错误提示 |
| 后台 | 表格 + 筛选 | 暂无数据 | toast |

## 5. 交互规范

- 行内操作「hover 浮现」（文件列表），保持界面干净
- 拖拽卡片：`cursor-grab` → `active:cursor-grabbing`，落列高亮
- 弹窗统一 `Modal` 组件：遮罩点击关闭 + 顶部标题栏 + 底部操作区
- 全屏 toast 居中底部 2.6s 自动消失，按 type 变色
- 通知红点：未读数 >99 显示 99+
- 页面切换 150ms 淡入；列表行 hover 60ms

## 6. 图标与视觉资产

- 图标用 Unicode/内联字符（树、文件类型、优先级点），不引入图标库依赖，保持 1 个字重风格
- 文件类型用 `fileIcon()` 映射（🖼🎬🎵🗜📄），与 kind 一一对应
- 头像：品牌色底 + 首字（无图时），圆形 `object-cover`

## 7. 响应式

- 布局：侧栏固定 224px，内容弹性；看板横向滚动（`overflow-x-auto`）
- 卡片网格 `grid-cols-2 lg:grid-cols-4`；后台表格 `min-w` + 横向滚动
- 登录页 1024px 以上双栏品牌区，以下单栏表单

## 8. 与 gold 标准的差距说明（诚实披露）

- 未引入真实摄影/插画资产（B 端工作台按规范本身就不以图为主）
- 动效仅保留页面过渡与 hover，未做 signature motion 引擎
- 未做多主题（暗色模式）——列为后续迭代项
