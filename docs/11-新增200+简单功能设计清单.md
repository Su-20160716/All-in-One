# 新增 200+ 简单功能设计清单（v7 · minitools）

> 文档性质：**执行清单 + 设计规约**。新建独立 Django app `minitools`，采用项目已验证的"目录驱动 catalog + 纯函数 run"模式，挂载 `/api/minitools/`，前端复用 `DomainExplorer.vue` 动态渲染，不为每个工具单独写页面。
>
> 全部工具为**无状态纯函数**（输入 → 输出，不落库、不依赖外部服务），每个工具 = 一个 Python 函数 + catalog 注册条目 + 一个 URL。
>
> 计数口径：9 大家族 × 共 210 个工具 = 210 项（含 catalog 共 211 个 URL）。

---

## 一、工程规约

### 1.1 目录结构

```
backend/minitools/
├── __init__.py
├── apps.py
├── common.py          # 复用 devtools/common.py 的 endpoint / ok / fail / req / p 等（直接 import）
├── catalog.py         # SUBSYSTEMS 定义 + catalog 视图
├── urls.py            # 路由装配 + _EXPECTED 契约断言
├── tools_text.py      # 文本处理家族
├── tools_num.py       # 数字数学家族

├── tools_validate.py  # 校验器家族
├── tools_convert.py   # 转换器家族
└── tools_fun.py       # 趣味家族
```

### 1.2 注册模式（与 devtools 完全一致）

```python
# urls.py
from django.urls import path
from .common import endpoint, endpoint_index, ok
from . import tools_text as text
# ... 其他家族

SUBSYSTEMS = [
    ("text", "文本处理", ["case-title", "case-sentence", ...]),
    ...
]

VIEWS = {
    "text/case-title/": text.case_title,
    ...
}

@endpoint(("GET",))
def minitools_catalog(request):
    return ok({
        "domain": "minitools", "domain_name": "迷你工具箱",
        "subsystems": [{"key": k, "name": n, "endpoints": eps,
                        "url_prefix": f"/api/minitools/{k}/"} for k, n, eps in SUBSYSTEMS],
        "subsystem_count": len(SUBSYSTEMS),
        "endpoint_count": sum(len(eps) for _, _, eps in SUBSYSTEMS) + 1,
        "endpoints": endpoint_index(urlpatterns),
    })

urlpatterns = [path("catalog/", minitools_catalog)]
for route, view in VIEWS.items():
    urlpatterns.append(path(route, view))

assert len(urlpatterns) == 211, f"minitools 接口数应为 211，实际 {len(urlpatterns)}"
```

### 1.3 函数签名约定

```python
@endpoint(("POST",))
def tool_name(request):
    text = req_str(request, "text")
    # 纯计算
    return ok({"result": ..., "detail": ...})
```

- 所有工具 POST 为主，入参从 JSON body 提取；
- 参数缺失/非法抛 `ValueError` → 400；其余异常 → 422（`endpoint` 装饰器自动兜底，**绝不 500**）；
- 响应统一 `{"ok": true, "data": {...}}`；
- 不引入任何第三方依赖（标准库 + Django + 项目已有包即可）。

### 1.4 装配点（只增不改）

1. `config/settings.py` → `INSTALLED_APPS` 追加 `"minitools"`
2. `config/urls.py` → 追加 `path("api/minitools/", include("minitools.urls"))`
3. 前端 `src/router/index.js` → 追加 `/toolbox/minitools` 路由（复用 DomainExplorer，props `domain="minitools"`）
4. 前端侧边栏 → 追加「迷你工具箱」入口
5. 前端 `src/api/index.js` → `suiteApi` 已支持任意 domain，无需改动

## 三、与既有工具的去重说明

| 既有工具（devtools/tools） | minitools 对应处理 |
|---|---|
| devtools text/case（大小写） | minitools 做更细分的 title/sentence/alternating/invert，不重复通用 case |
| devtools num/base（进制） | minitools 做任意进制 base-arbitrary（2-36），更通用 |
| devtools encode/base32/base85 | minitools 增加 base58/base64url/quoted-printable，不重复 |
| devtools fun/dice/coinflip/team-splitter | minitools 增加更多参数（任意面数、计数统计），功能增强而非重复 |
| tools 旧 34 工具（UUID/密码/哈希等） | minitools 增加多版本 UUID、可配置密码、多算法哈希，参数更丰富 |
| devtools color/* | minitools 增加色温/CMYK/和谐方案/WCAG文字建议，不重复 |

> 原则：minitools 聚焦"更细粒度、更多参数、更生活化"的工具，与 devtools 的"开发者向专业工具"形成互补，不做简单重复。
