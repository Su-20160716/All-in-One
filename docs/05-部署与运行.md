## 二、生产部署（Linux + Nginx + Gunicorn/Daphne + PostgreSQL）

### 1. 环境变量（`config/settings.py` 读取）

| 变量 | 默认 | 说明 |
|---|---|---|
| DJANGO_SECRET_KEY | dev-insecure... | **生产必须设置** |
| DJANGO_DEBUG | 1 | 生产设 0 |
| DJANGO_ALLOWED_HOSTS | * | 逗号分隔 |
| POSTGRES_DB / USER / PASSWORD / HOST / PORT | — | 设置后自动切换 PostgreSQL |
| REDIS_URL | — | 设置后启用 Redis Channel Layer |
| JWT_ACCESS_HOURS | 12 | access 有效期 |
| FILE_MAX_SIZE_MB | 1024 | 单文件上限 |
| FILE_CHUNK_SIZE_MB | 5 | 分片大小（前端 5MB，需一致） |

### 2. 步骤

```bash
# 后端
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt gunicorn
python manage.py migrate
python manage.py collectstatic --noinput
python manage.py seed

# 静态/媒体
# 建议 Nginx 直接托管 /static/ 与 /media/（MEDIA_ROOT = backend/media）

# 进程（ASGI，WebSocket 必须走 Daphne 或 uvicorn）
daphne -b 0.0.0.0 -p 8001 config.asgi:application
# 或 gunicorn 纯 HTTP：gunicorn config.wsgi:application
```

### 3. Nginx 示例

```nginx
server {
    listen 80;
    server_name your.domain;

    client_max_body_size 1100m;              # 大文件上传
    proxy_read_timeout 300s;

    location /api/  { proxy_pass http://127.0.0.1:8001; proxy_set_header Host $host; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; }
    location /media/ { alias /path/to/backend/media/; }
    location /static/ { alias /path/to/backend/staticfiles/; }
    location /share/ { proxy_pass http://127.0.0.1:8001; }

    location /ws/ {
        proxy_pass http://127.0.0.1:8001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    location / { proxy_pass http://127.0.0.1:5173; }   # 前端产物或 npm run preview
}
```

## 三、常见问题

| 问题 | 处理 |
|---|---|
| 上传 500 “number of GET/POST parameters exceeded” | 测试客户端编码问题；真实前端用 FormData 无此问题。仍出现则调大 `DATA_UPLOAD_MAX_NUMBER_FIELDS` |
| WebSocket 连不上 | 确认走 8000 端口的 Daphne/runserver（ASGI），非纯 WSGI；检查代理 `Upgrade` 头 |
| 迁移报错 | `python manage.py makemigrations <app>` 后 `migrate` |
| CORS 报错 | 开发默认全放开；生产收紧 `CORS_ALLOW_ALL_ORIGINS=False` + `CORS_ALLOWED_ORIGINS` |
| 大文件内存 | 分片后端逐块写盘不读内存；`_safe_join` 保证路径安全 |
